# Alya AI

Нейросеть, которая играет в osu!standard. Python + PyTorch (CUDA).

## Установка

```
python -m venv .venv
.venv\Scripts\python -m pip install numpy websockets
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cu128
```

## Конвейер

```
# 0. (опционально) синтетические карты для разминки
python main.py synth --out data/synth --count 200

# 1. датасет из своих реплеев (+ автоплей по синтетике)
python main.py bc-data --songs "C:/osu!/Songs" --replays "C:/osu!/Data/r" --autoplay-maps data/synth --out data/bc.npz

# 2. behavior cloning
python main.py bc --data data/bc.npz --out ckpt/bc.pt --steps 20000

# 3. PPO в симуляторе
python main.py ppo --maps "C:/osu!/Songs" --limit 500 --init ckpt/bc.pt --out ckpt/ppo.pt --mods NM HR DT HRDT

# 4. реплей для просмотра в osu! (перетащить .osr в окно игры)
python main.py export --model ckpt/alya.pt --map "путь/к/карте.osu" --mods HDDT --out alya.osr

# 5. живая игра (нужен запущенный tosu; моды берутся из tosu). Только оффлайн!
python main.py calibrate                 # курсор обводит углы поля — сверить с рамкой в игре
python main.py live --model ckpt/alya.pt --keys zx --dry-run   # проверка связи без мыши
python main.py live --model ckpt/alya.pt --keys zx --acc 0.96
```

`bc-data` печатает для каждого реплея счёт по симулятору и по игре — так видно,
насколько симулятор совпадает с настоящим osu!.

## Устройство

| файл | что делает |
|---|---|
| `alya/beatmap.py` | парсер .osu: Difficulty, TimingPoints, HitObjects, пути слайдеров L/P/B/C, длительности, тики |
| `alya/sim.py` | векторизованный симулятор: окна 300/100/50, радиус по CS, notelock, слайдеры (голова + тики/повторы/конец в follow circle 2.4r), спиннеры |
| `alya/env.py` | RL-среда: шаг 16 мс, награда 300/100/50/miss + шейпинг за приближение к цели |
| `alya/model.py` | MLP → GRU → (dx, dy) Гаусс, две клавиши K1/K2 Бернулли, value |
| `alya/osr.py` | чтение/запись .osr (LZMA) |
| `alya/bc.py`, `alya/ppo.py` | обучение |
| `alya/export.py` | прогон модели по карте → .osr |
| `alya/live.py` | tosu (websocket v2 + precise) → модель → SendInput |

Наблюдение: 8 следующих видимых (по AR) нот относительно курсора — dx, dy, время до ноты,
время до конца, тип, активна ли, прогресс слайдера/спиннера — плюс скорость и позиция курсора,
состояние K1/K2, CS/AR/OD. Клик = новое нажатие любой из двух клавиш, как в osu!.

Симулятор вызывается через `advance(время, позиция, клавиша)`, поэтому один и тот же код
считает состояние в RL, при разборе человеческих реплеев и в живой игре.

## Упрощения

- Стаки нот — алгоритм stable v6+. Моды EZ/HR/DT/NC/HT поддержаны (HR отражает карту, DT/HT переводят
  время в реальные мс). Реплеи с RX/Auto/AP/SpunOut пропускаются. Нет HP/фейла.
- Симулятор чуть строже игры на быстрых прыжках (клик на краю круга): на реплеях число 300 совпадает
  в пределах ~3%, промахов примерно вдвое больше, чем в игре.
- Пороги спиннера и поздний клик внутри слайдера приближены.
- Живая игра: геометрия поля для stable и lazer (тип клиента берётся из tosu), поправки
  `--offset-y` (положение) и `--offset-ms` (время). Время песни tosu присылает раз в POLL_RATE мс;
  между обновлениями оно экстраполируется. Клавиши по умолчанию Z/X. F8 — аварийная остановка.
  Если ты залогинен (stable), игра не начнётся — чтобы скоры бота не ушли на сервер.

## Важно

Живую игру используйте только оффлайн или без отправки скоров: бот в ранкеде нарушает правила osu!
и ведёт к бану аккаунта.

## Аля разговаривает (этап 1 витубера)

Характер — в `persona.md` (его можно править), память фактов — `data/memory.json`,
последние реплики — `data/chat_history.json`. Мозг — на выбор:

| бэкенд | цена | ключ |
|---|---|---|
| `gemini`, `gemini-lite` | бесплатный тариф с дневным лимитом (gemini-3.5-flash / -flash-lite) | `setx GEMINI_API_KEY "..."` (aistudio.google.com → Get API key) |
| `gemini2`, `gemini2-lite` | то же на запасном ключе | `setx GEMINI_API_KEY_2 "..."` |
| `groq` | бесплатный тариф | `setx GROQ_API_KEY "..."` (console.groq.com → API Keys) |
| `ollama` | бесплатно, локально на видеокарте | не нужен; поставить Ollama и `ollama pull qwen3:8b` |
| `claude` | платно | `setx ANTHROPIC_API_KEY "..."` |

```
python main.py chat                      # gemini-lite → gemini → gemini2-lite → gemini2 → ollama
python main.py chat --backend gemini-lite,gemini2-lite   # быстрее отвечает
python main.py chat --backend groq,ollama
python main.py chat --backend claude
python main.py chat --new                # без прошлых реплик (факты остаются)
```

Каждый ответ начинается с тега эмоции (`[smug]`, `[angry]`, ...) — по нему меняется выражение лица модельки.

По умолчанию Аля отвечает по-английски (`--lang ru` — по-русски), понимает оба языка.

### Голос и моделька (VTube Studio)

```
python main.py chat --vts                # голос Ana по умолчанию; --voice off — без голоса
python main.py chat --voice en-US-JennyNeural --pitch +25Hz --rate +8% --vts
```

- Голос — бесплатный Microsoft Edge TTS, без ключа (нужен интернет). Список голосов: `python -m edge_tts --list-voices`.
- `--vts` — ведёт модельку в VTube Studio: рот по голосу, лицо по эмоции, моргание и покачивание головой.
  В VTube Studio включи «Start API (allow plugins)» (порт 8001), при первом запуске нажми «Allow».
  Горячие клавиши модели, в названии которых есть эмоция (`happy`, `angry`, ...), нажимаются сами.
- Комментарии к игре: чат сам читает tosu и отвечает вслух на начало карты, слом большого комбо,
  круглые комбо без промахов, фейл, выход и итог карты. `--game alya` (по умолчанию) — играет бот,
  `--game creator` — играешь ты, она комментирует со стороны, `--game off` — без комментариев.

### Стрим на Twitch

Одной кнопкой — `start_stream.bat` (или `python main.py stream`): поднимает tosu, бота в отдельном окне
и Алю с голосом, VTube Studio, чатом и оверлеем. Настройки — в `stream.json` (создаётся при первом запуске; образец — `stream.example.json`):
путь к tosu, канал Twitch, модель, клавиши, точность, голос. Уже запущенные tosu или бот второй раз не
стартуют; когда закрываешь Алю, бот, запущенный отсюда, тоже останавливается.

Вручную то же самое:
```
python main.py chat --vts --twitch имя_канала
```

- **Заказ карт:** зритель пишет `!req <ссылка на карту>` (или номер сложности), можно с модами: `+HD`, `+HR`,
  `+DT`, `+HDDT`, `+HDHR` (NC = DT; DT — только на картах до 7★; FL, EZ и наборы вроде HDDTHR не принимаются). Карта берётся с зеркала
  osu.direct, только osu!standard, не NSFW и не длиннее 5 минут, по одной от зрителя, до 10 в очереди. Аля комментирует заказ,
  очередь видна на оверлее. Следующий заказ открываешь ты: **Ctrl+Shift+N** в любом окне или `/next` в окне Али —
  карта скачивается и открывается в osu!. `/заказы` — показать очередь.
- **Автопилот** (Ctrl+A в окне osu! или `/auto`): Аля сама ходит по меню osu! и играет заказы по очереди —
  находит карту в выборе песни, объявляет, жмёт Enter, после результатов возвращается в выбор песни и
  делает паузу на чат. Если заказов нет — выбирает карту сама: F2 (случайная карта) и стрелками до
  сложности на 6.5–9.3★ с выбранными сейчас модами, не длиннее 5 минут, без повторов за стрим
  (`OWN_STARS` в `alya/autopilot.py`). Если карта стоит на паузе дольше 10 с (osu! ставит её сам, когда окно теряет фокус), автопилот её бросает и берёт следующую. Пока он включён,
  окно osu! держится на переднем плане и клавиши заняты (голосом в Discord сидеть можно).
- **Фильтр речи** (`alya/safety.py`): каждая её фраза перед озвучкой и субтитрами проверяется на то, за что
  банят канал (оскорбления групп, призывы к самоубийству и насилию, сексуальное, нацизм; ловит и «leet» вроде
  n1gg@ и r e t a r d) — вместо неё звучит отговорка. Такие же сообщения из чата до неё не доходят.
  Обычный мат (fuck, shit) разрешён: она иногда ругается, когда чоукает под конец карты.
- **Память о зрителях** (`data/viewers.json`): кто пишет впервые, кто постоянный, на скольких стримах был,
  что писал в прошлый раз. Факты о зрителях Аля запоминает сама («Зритель ник: ...»).
- **Заставки:** `http://localhost:24080/scene.html?mode=starting` (скоро начнётся), `?mode=brb` (отошла),
  `?mode=end` (конец стрима) — в том же стиле, с чатом, её субтитрами и каракулем, который рисуется на глазах.

- `--twitch` — читает чат канала без аккаунта и токена (анонимный вход, только чтение). Отвечает не чаще раза
  в 8 с, из накопившегося выбирает одно-два сообщения и обращается по нику. Команды (`!...`), ссылки и
  боты (Nightbot, StreamElements...) пропускаются.
- Оверлей для OBS включён всегда: `http://localhost:24080/` (`--overlay 0` — выключить). На нём субтитры
  синхронно с голосом и эмоция, чат, карта из tosu (название, звёзды, моды, точность, комбо, pp, прогресс).
  `?only=captions`, `?only=chat`, `?only=map` — один блок для своей раскладки, `?nobg` — без фона.

Сцены в OBS собирает `python main.py obs-setup` (в OBS: Сервис → Настройки сервера WebSocket →
включить сервер, без входа в аккаунт). Создаётся отдельная коллекция сцен «Alya», холст 1920×1080, 60 к/с:
- **Alya — скоро / игра / отошла / конец**: оверлей или заставка, захват osu! ровно в окно игры,
  VTube Studio поверх (верх окна с кнопками обрезан), «Звук рабочего стола» и выключенный микрофон.
- В VTube Studio фон: выбор цвета, чёрный, галочка «Transparent in capture». Моделька стоит в правом
  нижнем углу окна VTube Studio — так она попадает в угол сцены.
- Повторный запуск пересобирает сцены той же раскладкой. Ключ трансляции вводишь сам: Настройки → Трансляция.
